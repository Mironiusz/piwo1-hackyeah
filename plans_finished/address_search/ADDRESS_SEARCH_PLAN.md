## Decisions

D-1. The endpoint is asynchronous: `async def`, with `httpx.AsyncClient` and the whole outgoing call, connection, request and the full body, inside `asyncio.timeout(5.0)`, so the 5 seconds of `GEOCODING_PLAN.md` D-10 bound the whole call (F-5, F-17, F-18). The gate and the cache live in the event loop of the one process (F-11) and need no `threading.Lock`, because no `await` stands between reading and updating them. This departs, for this endpoint only, from the plain `def` and the `threading.Lock` of `BACKEND_ARCHITECTURE_PLAN.md` D-2 (F-7). The thread pool of `docs/standards/standard_architecture.md`, section Calls to external systems, exists to keep a blocking call off the event loop; this call does not block it, so the rule is met by non-blocking input and output instead of a thread. Decided by Rafał on 2026-10-04 in place of Mateusz, against a plain `def` with a limit of 5 seconds per phase, which lets a stalled answer last 10 - 15 seconds.

D-2. The three modules keep the names of `BACKEND_ARCHITECTURE_PLAN.md` D-13 (F-7) with two changes forced by the gates. The data layer raises its own `NominatimRequestError`, and the rules layer defines `AddressSearchUnavailableError` and `InvalidSearchTextError`, which the input layer maps, because `api` may not import `data` (F-12) and every exception name ends in `Error` (F-13). `fetch_address_suggestions` returns `tuple[AddressSuggestion, ...]` instead of a list, so that a cached answer cannot be changed by a caller. Agent decision at C:40, without asking.

D-3. `data/nominatim.py` holds the constants `NOMINATIM_SEARCH_URL = "https://nominatim.openstreetmap.org/search"`, `NOMINATIM_USER_AGENT = "piwo1-hackyeah (HackYeah 2026 accessibility prototype)"`, `NOMINATIM_SEARCH_PARAMETERS`, a `dict[str, str]` of the seven fixed parameters of F-5 in that order, and `NOMINATIM_TIMEOUT_SECONDS = 5.0` (F-36). `build_nominatim_client(transport: httpx.AsyncBaseTransport | None = None) -> httpx.AsyncClient` builds a client with the header `User-Agent` only, `timeout=NOMINATIM_TIMEOUT_SECONDS`, `trust_env=False` and `follow_redirects=False` (F-15, F-22); a new client per call keeps no cookie between searches, and the connection setup it repeats costs nothing against one call per 1.1 seconds. `fetch_nominatim_places(text: str) -> list[NominatimPlace]` sends `params={"q": text, **NOMINATIM_SEARCH_PARAMETERS}` once, without retry, inside `asyncio.timeout(NOMINATIM_TIMEOUT_SECONDS)`. Agent decision at C:40, without asking.

D-4. `NominatimRequestError(cause: str, status: int | None = None)` keeps `cause` and `status` as attributes and the message `Nominatim request failed cause=<cause> status=<status>`, never the text or the URL. The causes are: `timeout` for `TimeoutError` or `httpx.TimeoutException`; `connection` for any other `httpx.HTTPError`; `status` with the code for any status other than 200; `invalid_body` when `build_nominatim_places` refuses the body. `raise_for_status` is not used, because its message holds the URL with the text (F-20). Agent decision at C:40, without asking.

D-5. `build_nominatim_places(body: bytes) -> list[NominatimPlace]` parses the body with `json.loads` and raises `NominatimRequestError("invalid_body")` when it is not JSON, not a list, or holds an item that is not an object, has no `lat` or `lon` string that parses as a finite float, or has an `address` that is not an object. `NominatimPlace` is a frozen dataclass of `name`, `road`, `house_number`, `neighbourhood`, `quarter`, `suburb`, `city_district`, `postcode` and `city`, each `str | None`, and `lat` and `lon` as `float`; a value that is not a string or is blank becomes `None`. Nothing else of the answer is kept. Agent decision at C:40, without asking: a malformed result is a body that is not the expected JSON of `GEOCODING_PLAN.md` D-11, and a missing optional part only shortens the label.

D-6. `service/address_search.py` holds `SEARCH_TEXT_MAX_LENGTH = 200`, `REMOVED_STREET_WORDS = frozenset({"ul.", "ulica"})`, `KRAKOW_CITY = "Kraków"`, `CACHE_TIME_TO_LIVE_SECONDS = 86400.0`, `CACHE_MAX_ENTRIES = 1000`, `GATE_INTERVAL_SECONDS = 1.1` and `GATE_MAX_WAIT_SECONDS = 3.0` (F-5, F-36). `resolve_search_text(text: str) -> str` raises `InvalidSearchTextError` when `len(text)` exceeds 200 code points, splits the text on whitespace with `str.split()`, drops every word whose `casefold()` is in `REMOVED_STREET_WORDS`, joins the rest with one space and raises `InvalidSearchTextError` when nothing is left. A character is a code point, as the contract counts it for the account inputs (F-3). Agent decision at C:40, without asking.

D-7. `build_address_label(place: NominatimPlace) -> str` follows F-6, comparing the name with `road` only, as the ruling of 2026-10-04 words it, so a name equal to the estate stays in the label. `build_address_suggestions(places: Sequence[NominatimPlace]) -> tuple[AddressSuggestion, ...]` keeps the places whose `city` equals `KRAKOW_CITY`, labels them in the order received and drops a suggestion whose label is already in the tuple. `AddressSuggestion` is a frozen dataclass of `label: str`, `lat: float` and `lon: float`. Agent decision at C:40, without asking.

D-8. `SearchCache` keeps an `OrderedDict[str, tuple[float, tuple[AddressSuggestion, ...]]]` of the instant of storing and the answer. `fetch_suggestions(key: str, now: float) -> tuple[AddressSuggestion, ...] | None` returns `None` for a missing entry and removes and returns `None` for an entry with `now - stored_at >= CACHE_TIME_TO_LIVE_SECONDS`. `apply_suggestions(key: str, suggestions: tuple[AddressSuggestion, ...], now: float) -> None` stores the entry as the newest and removes the oldest stored entries while more than `CACHE_MAX_ENTRIES` remain. Its time to live is its invalidation strategy and its scope is the process (F-24, F-38). Agent decision at C:40, without asking.

D-9. `SearchGate` keeps the instant `next_start_at`, starting at negative infinity. `resolve_wait_seconds(now: float) -> float | None` takes the turn at `max(now, next_start_at)`; when the turn is more than `GATE_MAX_WAIT_SECONDS` away it returns `None` and changes nothing, otherwise it sets `next_start_at` to the turn plus `GATE_INTERVAL_SECONDS` and returns the wait. A refused search therefore takes no turn, and five searches at one instant wait 0, 1.1 and 2.2 seconds while the fourth and fifth are refused (`ADDRESS_SEARCH_SHAPE.md`, scenario 6). Agent decision at C:40, without asking.

D-10. `fetch_address_suggestions(text: str) -> tuple[AddressSuggestion, ...]` runs in this order: `resolve_search_text`; the cache key `casefold()` of the normalized text; a cache hit is returned; otherwise `SEARCH_GATE.resolve_wait_seconds(fetch_monotonic_seconds())`, where `None` logs a warning `Address search refused by the gate` and raises `AddressSearchUnavailableError`; `await sleep(wait)` with `sleep` imported from `asyncio`; `fetch_nominatim_places` with the normalized text, not the case-folded key; on `NominatimRequestError` an error entry `Address search unavailable cause=%s status=%s elapsed_ms=%.0f` with `exc_info=True` and `AddressSearchUnavailableError` raised from it; on success `build_address_suggestions` stored with `SEARCH_CACHE.apply_suggestions` and returned. `SEARCH_CACHE = SearchCache()` and `SEARCH_GATE = SearchGate()` are the process instances. A caller error is not logged (F-25). Agent decision at C:40, without asking.

D-11. `api/address_search.py` holds `SearchAddressRequest`, a Pydantic model with `ConfigDict(extra="forbid", strict=True)`, the field `text: str` and the field validator `resolve_utf8_text`, which encodes the text to UTF-8 so that a lone surrogate is refused as `invalid_request` with `fields` `["text"]` instead of failing in httpx (F-19, F-20, F-21), as the contract refuses it for the account inputs (F-3). `fetch_address_matches(body: SearchAddressRequest) -> JSONResponse` awaits `fetch_address_suggestions`, answers `build_address_search_response`, and maps `InvalidSearchTextError` to `build_error_response("invalid_search_text", 422)` and `AddressSearchUnavailableError` to `build_error_response("address_search_unavailable", 503)`. `build_address_search_response(suggestions: tuple[AddressSuggestion, ...]) -> dict[str, object]` gives `{"matches": [{"label": ..., "point": {"lat": ..., "lon": ...}}]}`. `apply_address_search_routes(app: FastAPI) -> None` registers `fetch_address_matches` with `app.add_api_route("/api/address-search", ..., methods=["POST"], name="search_address", response_model=None)`, and `build_app` gains one call of it (F-8, F-9, F-14). The endpoint declares no header, so `Authorization` is never read and no session is renewed. Agent decision at C:40, without asking.

D-12. The tests use no network and run asynchronous code with `asyncio.run` inside plain test functions, without a new test dependency. The recorded answers of F-28 are copied, trimmed to the fields D-5 reads plus `licence`, into `tests/common_nominatim_answers.py` as the constant `RECORDED_ANSWERS: dict[str, list[dict[str, object]]]` keyed by the searched text, with the ODbL attribution in its module docstring; no test reads the archive. A fake transport enters by replacing `data.nominatim.build_nominatim_client` with `functools.partial` of the real function and an `httpx.MockTransport`, so the real headers and parameters are tested.
