Negative identifier compatibility is checked through the existing detail, vote and moderation interfaces. The user chose this convention on 2026-10-04 in Kuba's place; the handoff explicitly records the outstanding team confirmation without claiming delivered consumer support. ## Risks

- R-1. The shared backend and common loader are not delivered in the current tree. Their named contracts are documented; no private replacement is permitted. A future conflicting delivery requires reconciling the plan before continuing.
- R-2. The user approved negative sample identifiers in Kuba's place. A consumer that adds a positive-only validation would reject legitimate sample facts even though the existing public contract specifies only an integer. The joint interface checks must detect this before the demo.
- R-3. Public OSM geometry and tags can differ from the Geofabrik source copy. The loader fails on missing or changed prerequisites rather than relocating samples or overriding source data. The source download is planning evidence, not an imported-copy rehearsal.
- R-4. The demonstration route is not yet agreed. The selected S-1 corridor and nearby S-3 are an explicit handoff; joint route evidence remains required. Existing votes or hiding can legitimately change the next demo scene, and retry must preserve those contributions.
- R-5. Concurrent Repeatable Read writers can fail serialization, and connection loss around commit can be uncertain. The provider reports those failures truthfully; stable primary keys support manual recovery without duplicate facts or refreshed author votes. Full-flow exclusion remains with the common loader.
- R-6. Critical fixtures need local owner cleanup because runtime grants forbid deleting facts and votes. They must refuse occupied fixture keys and use exact registered rows; a broad reset or cleanup of existing samples would lose real contributions.
- R-7. Docker was inaccessible and the development/check dependencies were absent in this session. Applied-schema, SQL, library resolution, distance, timeout and end-to-end evidence has not yet been obtained. Planning must not be read as a passed implementation review.
