Repository piwo1-hackyeah holds EnableMe, a HackYeah 2026 project: a community app about the accessibility of places in Kraków, built from open data and people's reports with photos, with routes matched to the needs of people with different disabilities - web first, a HarmonyOS port if time allows, for the challenges "Kraków bez barier" and Huawei "Imagine What's Next" (requirements: docs/hackathon/challenge_requirements.md).
The source of truth for the product is docs/product/specification.md - it prevails over anything else; it settles the target group and the MVP scope, and every question about product behavior it does not describe goes to the user. Everything in the repository is written in English, the conversation with the user is in Polish.
